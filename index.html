My First Web Page

Hypertext Markup Language (HTML) is the standard markup language used to create and structure documents displayed on the World Wide Web. Invented by Tim Berners-Lee in 1991, it serves as the foundational skeleton of virtually every website by using a system of tags and elements to define content like headings, paragraphs, links, and images. Rather than being a programming language, HTML is a static layout language interpreted by web browsers.
